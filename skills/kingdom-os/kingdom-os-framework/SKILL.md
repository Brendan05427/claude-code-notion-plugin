# Kingdom OS Framework

The Kingdom OS is a personal and professional operating system that combines Kingdom leadership architecture with the Second Brain CODE/PARA methodology. The foundational principle is: **order precedes multiplication; structure precedes the supernatural.**

## Core Philosophy

| Principle | Meaning |
|---|---|
| Fix the Man. Fund the Mission. | Character formation precedes resource allocation. |
| Order precedes multiplication | Structure must be installed before scale is attempted. |
| God funds His assignment, not distraction | Aligned effort attracts provision; scattered effort does not. |
| Goshen Principle | An ordered life creates a structure where favor has somewhere to land. |
| The business is an assignment | Every enterprise is stewardship, not self-expression. |

## The Four-Layer Operating System

| Layer | Core Question | Kingdom Principle | Second Brain Function |
|---|---|---|---|
| Identity | Who am I becoming before God? | Fix the Man. Fund the Mission. | Distill identity statement |
| Purpose | What assignment am I stewarding? | God funds His assignment, not distraction | Organize projects and areas |
| Disciplines | What rhythms keep the structure? | Order precedes multiplication | Capture, review, and execute |
| Outputs | What fruit, deliverables, and evidence? | The business is an assignment | Express organized knowledge |

## Nine Kingdom Domains

Every activity, project, and rhythm belongs to one of these domains:

1. **Spiritual Formation** — Scripture, prayer, formation, worship, revelation
2. **Business & Stewardship** — Revenue, operations, team, systems, enterprise
3. **Family & Marriage** — Presence, covenant, children, household order
4. **Health & Energy** — Body stewardship, movement, nutrition, rest, longevity
5. **Ministry & Calling** — Preaching, discipleship, community impact, spiritual gifts
6. **Finances & Generosity** — Wealth building, giving, stewardship, budgets
7. **Leadership & Team** — Team formation, culture, delegation, accountability
8. **Learning & Wisdom** — Books, courses, mentorship, insight capture
9. **Community & Brotherhood** — Brotherhood, council, peer accountability

## CODE Methodology (Second Brain)

```
Capture  → Capture every insight, scripture, idea before it disappears
Organize → Route to the correct PARA category and Kingdom domain
Distill  → Extract the principle or action from the raw content
Express  → Translate distilled knowledge into Kingdom outputs and fruit
```

## PARA Kingdom Configuration

Each domain has four containers:

| PARA | Purpose | Review Cadence |
|---|---|---|
| Project | 90-day outcome with a defined finish line | Weekly |
| Area | Long-term responsibility and standard to maintain | Monthly |
| Resource | Reusable notes, scriptures, teachings, playbooks | Quarterly |
| Archive | Inactive material preserved without clutter | As needed |

## Domain Scoring System

Use a 1–5 scale for all domain health scores:

| Score | Meaning | RAG |
|---|---|---|
| 5 | Thriving — bearing consistent fruit, no disorder | Green |
| 4 | Healthy — ordered, some room to grow | Green |
| 3 | Watch — functioning but needs attention | Watch (yellow) |
| 2 | Amber — clear disorder, correction needed soon | Amber |
| 1 | Red — crisis, broken structure, urgent action needed | Red |

## Behavioral Defaults

- Always identify which Kingdom domain an action belongs to before logging it
- Never create Notion entries without first confirming the correct database
- When scoring a domain, ask for the primary disorder to address and the next order step
- Prefer distilled principles over verbose summaries
- Frame every project and action as stewardship of a Kingdom assignment, not personal ambition
